# 🍏 FoodSaver

FoodSaver är en fullstack-applikation byggd för att minska matsvinn genom smart hantering av kylskåpets innehåll, dynamiska receptrekommendationer och gamification.

## ✨ Huvudfunktioner

*   **Smart Receptmotor:** Jämför automatiskt användarens befintliga kylskåpsinnehåll med en receptdatabas och rekommenderar maträtter som minimerar behovet av nyinköp.
*   **Sömlös Inköpslista:** Varor som handlas och checkas av från inköpslistan flyttas dynamiskt direkt in i det digitala kylskåpet via API-anrop.
*   **Gamification (Poängsystem):** Användare belönas med poäng för att äta upp mat innan bäst före-datumet går ut, komplett med en dynamisk topplista.

## 🛠 Teknisk Stack

*   **Frontend:** React, TypeScript, Tailwind CSS, Lucide Icons
*   **Backend:** Python, FastAPI
*   **Databas:** SQLite
*   **Arkitektur:** REST API med tydlig separation mellan klient och server.
